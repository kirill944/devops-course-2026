\# Конфигурация виртуальной машины devops-vm



\## 1. Параметры машины

\*   Объём оперативной памяти: 2048 МБ

\*   Количество ядер процессора: 2

\*   Объём дискового накопителя: 25 ГБ, динамически расширяемый



\## 2. Сетевые интерфейсы

\*   \*\*Адаптер 1 (NAT):\*\* Адрес `10.0.2.15`. Обеспечивает доступ в Интернет (для обновления пакетов).

\*   \*\*Адаптер 2 (Host-only):\*\* Адрес `192.168.56.101`. Обеспечивает доступ с хостовой системы к веб-серверу и SSH.



\## 3. Правило проброса портов

\*   Порт хостовой системы: `2223`

\*   Порт гостевой системы: `2223` (SSH перенастроен на этот порт в ПР №5)



\## 4. Учётные записи

\*   `student`: входит в группу `sudo`, вход по паролю (используется для первичной настройки).

\*   `devops`: входит в группу `sudo`, вход по SSH-ключу (основная рабочая учетная запись).

\*   `www-data`: системная учетная запись для работы веб-сервера Nginx, не имеет прав на запись файлов сайта.



\## 5. Служба SSH

\*   \*\*Порт:\*\* 2223

\*   \*\*Расположение конфигурации:\*\* `/etc/ssh/sshd\_config.d/99-hardening.conf`

\*   \*\*Изменённые директивы:\*\*

&#x20;   \*   `Port 2223`

&#x20;   \*   `PermitRootLogin no`

&#x20;   \*   `PasswordAuthentication no`

&#x20;   \*   `PubkeyAuthentication yes`

&#x20;   \*   `PermitEmptyPasswords no`

&#x20;   \*   `MaxAuthTries 3`

&#x20;   \*   `LoginGraceTime 30`

&#x20;   \*   `AllowUsers devops`

&#x20;   \*   `X11Forwarding no`



\## 6. Правила межсетевого экрана (UFW)

\*   Политика по умолчанию: `deny incoming`, `allow outgoing`

\*   Правила:

&#x20;   \*   `2223/tcp` — LIMIT (SSH rate-limited)

&#x20;   \*   `80/tcp` — ALLOW (HTTP)

&#x20;   \*   `443/tcp` — ALLOW (HTTPS)



\## 7. Снимки состояния

\*   `01-clean-install` — после установки ОС

\*   `02-keys-Configured` — после настройки ключей

\*   `03-ssh-hardened` — после настройки SSH (ПР №5)

\*   `04-nginx-https` — после настройки Nginx и HTTPS (ПР №6)



\## 8. Веб-сервер

\*   \*\*Устанавливаемый пакет:\*\* `nginx` (установлен командой `sudo apt install -y nginx`).

\*   \*\*Путь к конфигурации ресурса:\*\* `/etc/nginx/sites-available/devops-site` (активирован символической ссылкой в `/etc/nginx/sites-enabled/`).

\*   \*\*Каталог ресурса:\*\* `/var/www/devops-site`.

&#x20;   \*   \*\*Владелец:\*\* `devops:devops`.

&#x20;   \*   \*\*Права:\*\* `755` для каталога, `644` для файлов.

\*   \*\*Сертификат (открытая часть):\*\* `/etc/ssl/certs/devops.crt`.

&#x20;   \*   \*\*Права:\*\* `644`, владелец `root`.

\*   \*\*Закрытый ключ TLS:\*\* `/etc/ssl/private/devops.key`.

&#x20;   \*   \*\*Права:\*\* `600`, владелец `root`.

\*   \*\*Команда формирования сертификата:\*\*

&#x20;   `sudo openssl req -x509 -nodes -days 365 -newkey rsa:2048 -keyout /etc/ssl/private/devops.key -out /etc/ssl/certs/devops.crt -subj "/CN=devops.local" -addext "subjectAltName=DNS:devops.local"`

\*   \*\*Срок действия сертификата:\*\* 365 дней.
